# services/ (archived)

This directory is an **archived, unmaintained** microservices prototype (auth, user, rider,
order, product, cart, payment, notification, location, tracking-gw, analytics), scaffolded
on 2026-03-29 together with `shared/` (protobuf definitions).

- It is **not deployed** and **not built or tested in CI**.
- It is **superseded by `backend/`**, the NestJS monolith that the customer app, rider app
  and admin dashboard actually use.
- Do not add features or fixes here. Make changes in `backend/`.

The code is kept for reference only and may be deleted in the future.
